🪐 Age API

Calculate your age across all planets in our solar system

Each planet orbits the sun at its own speed, so you'll have a different birthday celebration every time a planet completes a full orbit from when you were born.

Overview

The Age API calculates your age across all planets in our solar system. Each planet has its own orbital period, so you'll celebrate your birthday at different times depending on which planet you're measuring.

How it works

Send your birthday in DD-MM-YYYY format with a time in HH:MM, and get back:

  • Your age on each planet (in planet-years)
  • The next birthday date for each planet
  • A countdown to each upcoming birthday

Timezone Support

The API supports timezone handling through the optional tz parameter. This lets you specify your birthday in your local time, and the API converts it to UTC internally.

Endpoints

GET /exec

Calculate age on all planets for a given birthday.

Method: GET
Authentication: None required
Rate Limit: Google Apps Script quotas apply

Parameters

Query Parameters

Parameter Type Required Description
bday string Yes Birthday in format DD-MM-YYYYTHH:MM[Z]. The optional Z suffix indicates UTC.
tz number No Timezone offset in hours from UTC (e.g., 2 for GMT+2, -5 for EST). Range: -14 to +14.

Parameter Details

bday (required)

Your birthday in DD-MM-YYYYTHH:MM format, optionally suffixed with Z for UTC.

  • 21-08-2003T13:17Z — August 21, 2003 at 1:17 PM UTC
  • 21-08-2003T13:17 — Same time (no Z), defaults to UTC

tz (optional)

Timezone offset in hours. When provided, the Z suffix on bday is ignored.

  • tz=2 — GMT+2 (Central European Summer Time)
  • tz=-5 — GMT-5 (Eastern Standard Time)
  • tz=5.5 — GMT+5:30 (India Standard Time)
Timezone Offset Explanation: The tz parameter represents the offset to subtract from the wall-clock time to get UTC. So tz=2 means your local time is GMT+2, and the API subtracts 2 hours to convert to UTC.

Response Format

Success Response (HTTP 200)

{ "bday": "2003-08-21T13:17:00Z", "tzOffsetHours": 2, "now": "2026-08-09T12:34:56.789Z", "planets": { "mercury": { "label": "Mercury", "orbitalPeriodDays": 87.9691, "age": 262.15, "nextBirthday": { "date": "2026-08-19T13:17:00Z", "countdown": { "milliseconds": 864000000, "formatted": "10d 00:00:00" } } }, "earth": { ... }, "mars": { ... } } }

Response Fields

Field Type Description
bday ISO 8601 string Your birthday in UTC
tzOffsetHours number Timezone offset applied (0 if not specified)
now ISO 8601 string Current time in UTC
planets object Age data for each planet (keyed by planet name)

Planet Object Fields

Field Type Description
label string Display name of the planet/body
orbitalPeriodDays number How many Earth days it takes to orbit the sun
age number Your age in planet-years (can be fractional)
nextBirthday object Birthday info (date and countdown)

Countdown Object

Field Type Description
milliseconds number Milliseconds until next birthday
formatted string Human-readable format: Xd HH:MM:SS

Examples

Basic Request (UTC)

If you were born in UTC:

GET /exec?bday=21-08-2003T13:17Z

August 21, 2003, 1:17 PM UTC

With Timezone Offset (GMT+2)

If you were born in Central European Summer Time:

GET /exec?bday=21-08-2003T13:17&tz=2

Same date/time, but in GMT+2. The API converts to UTC internally.

Negative Timezone (EST, GMT-5)

For timezones west of UTC:

GET /exec?bday=15-03-1990T09:45&tz=-5

March 15, 1990, 9:45 AM EST (UTC−5)

Fractional Timezone (IST, GMT+5:30)

Some timezones use half-hour or quarter-hour offsets:

GET /exec?bday=10-12-1985T16:30&tz=5.5

December 10, 1985, 4:30 PM IST (UTC+5:30)

JavaScript (Fetch)

const bday = "21-08-2003T13:17Z"; const tz = 2; const url = new URL("https://script.google.com/macros/s/AKfycbwOaB208tRwpGv4Fq2uwEHNGBz_ghsDEJnQuHCsTTi0GBaMxo2mYixl8tHhYkKLbkksHQ/exec"); url.searchParams.append("bday", bday); url.searchParams.append("tz", tz); fetch(url) .then(res => res.json()) .then(data => { console.log(`You are ${data.planets.earth.age.toFixed(2)} years old on Earth`); console.log(`Next birthday: ${data.planets.earth.nextBirthday.countdown.formatted}`); });

Python

import requests bday = "21-08-2003T13:17Z" tz = 2 url = "https://script.google.com/macros/s/AKfycbwOaB208tRwpGv4Fq2uwEHNGBz_ghsDEJnQuHCsTTi0GBaMxo2mYixl8tHhYkKLbkksHQ/exec" params = {"bday": bday, "tz": tz} response = requests.get(url, params=params) data = response.json() print(f"Earth age: {data['planets']['earth']['age']:.2f} years") print(f"Next birthday: {data['planets']['earth']['nextBirthday']['countdown']['formatted']}")

Error Handling

HTTP Status Codes

Status Meaning
200 Success. Parse the planets object for your data.
400 Bad request. Check the error field for details.

Error Response (HTTP 400)

{ "error": "Missing 'bday' parameter.", "expectedFormat": "DD-MM-YYYYTHH:MM[Z]", "example": "/exec?bday=21-08-2003T13:17Z", "exampleWithTz": "/exec?bday=21-08-2003T13:17&tz=2" }

Common Error Cases

Missing bday parameter

error: "Missing 'bday' parameter."

Invalid bday format

error: "Could not parse 'bday'. Expected format DD-MM-YYYYTHH:MM[Z]"

Invalid tz value

error: "Invalid 'tz'. Expected a number of hours between -14 and 14, e.g. tz=2 or tz=-5.5"

Birthday in the future

error: "Birthday is in the future."
bday: "2030-08-21T13:17:00Z"

Invalid date (e.g., February 30)

error: "Could not parse 'bday'. Expected format DD-MM-YYYYTHH:MM[Z]"
