My Projects API

GET .../exec

Overview

Read-only API backed by the Dati grezzi 2 sheet. Every request is a GET to the endpoint above; the action query parameter picks the behavior. No auth, no body — all input comes through the URL.

Every response is JSON with a status field of either success or error.

Row shape

Each record returned mirrors the sheet's header row exactly:

ColumnTypeNotes
NumeronumberRow / entry number
ProgettostringProject name — searchable
Iniziostring / timeStart time
Finestring / timeEnd time
Duratastring / numberDuration
DatastringDate — filterable via substring match
NotestringFree text — searchable

Endpoints

GET ?action=(none)

Default endpoint. Returns every row in the sheet as an array of objects, plus a total count.

?exec
// 200
{
  "status": "success",
  "total": 42,
  "data": [
    { "Numero": 1, "Progetto": "Sito Web", "Inizio": "09:00", "Fine": "11:30", "Durata": "2:30", "Data": "2026-08-18", "Note": "..." },
    // ...
  ]
}
GET ?action=latest

Returns the single most recent row — the last row in the sheet, not sorted by date.

?exec?action=latest
// 200
{
  "status": "success",
  "data": { "Numero": 42, "Progetto": "Sito Web", "...": "..." }
}
If the sheet has no rows beyond the header, data is null.
GET ?action=search

Case-insensitive substring match against Progetto or Note.

Query params
querytext to search for (empty string matches everything)
?exec?action=search&query=sito
// 200
{
  "status": "success",
  "count": 3,
  "data": [ /* matching rows */ ]
}
GET ?action=date

Substring match against the Data column — useful for matching a full date or just a year/month prefix.

Query params
valdate string or fragment, e.g. 2026-08
?exec?action=date&val=2026-08-18
// 200
{
  "status": "success",
  "count": 5,
  "data": [ /* matching rows */ ]
}

Errors

Any exception thrown server-side (bad sheet name, malformed data, etc.) is caught and returned as a 200 response with an error status rather than an HTTP error code:

"status": "error",
"message": "..."
Since this always returns HTTP 200, check the status field in the body — don't rely on the response code to detect failure.

Notes for callers

The sheet name Dati grezzi 2 is hardcoded with a fallback to the active sheet. If the sheet is renamed, requests silently fall back to whatever sheet is currently active — worth watching for.

CORS is not explicitly configured beyond the default Apps Script behavior; browser-based cross-origin calls may need testing against your specific origin.
