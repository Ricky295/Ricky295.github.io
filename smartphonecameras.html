📷 Smartphone Cameras API

A tiny JSON API, built on Google Apps Script, for publishing and retrieving sample photos taken by different phone cameras.

Base URL https://script.google.com/macros/s/AKfycbzT-FyJIwEkqRFWpDWeK4tgrYjEcpxDQH6wGKn_lkFuzQRkNXFO_Oq8JbFbrf2JBW14fw/exec
GET only JSON responses No auth required

Endpoints

GET ?method=publish

Adds a new photo entry for a given phone.

ParamTypeRequiredDescription
image-linkstring (URL)YesDirect http(s) link to the image
phonestringYesPhone id — lowercase, no spaces (e.g. oneplus7t)
Example request
GET /exec?method=publish&image-link=https://picsum.photos/400&phone=oneplus7t
Example response
{
  "success": true,
  "message": "Photo published",
  "phone": "oneplus7t",
  "image_link": "https://picsum.photos/400",
  "timestamp": "2026-08-14T17:48:43.372Z"
}
GET ?method=see_photo

Returns one or more random photos previously published for a phone.

ParamTypeRequiredDescription
phonestringYesPhone id to query
photosintegerNoHow many random photos to return. Default 1. Capped automatically at however many exist.
Example request
GET /exec?method=see_photo&phone=oneplus7t&photos=2
Example response
{
  "success": true,
  "phone": "oneplus7t",
  "requested": 2,
  "returned": 2,
  "total_available": 2,
  "photos": [
    "https://picsum.photos/401",
    "https://picsum.photos/400"
  ],
  "details": [
    { "image_link": "https://picsum.photos/401", "timestamp": "2026-08-14T17:49:00.815Z" },
    { "image_link": "https://picsum.photos/400", "timestamp": "2026-08-14T17:48:43.372Z" }
  ]
}
If photos exceeds how many are stored, you'll simply get all of them back — check returned vs requested in the response.
GET ?method=list_phones

Lists every phone id that has at least one published photo, with a count for each.

Example request
GET /exec?method=list_phones
Example response
{
  "success": true,
  "phones": ["oneplus7t"],
  "counts": { "oneplus7t": 2 }
}

Errors

All errors return HTTP 200 with "success": false and an error message — check that field rather than the status code.

{
  "success": false,
  "error": "No photos found for phone: unknownphone",
  "phone": "unknownphone"
}

Notes

  • Phone ids are automatically lowercased and stripped of spaces — OnePlus 7T and oneplus7t resolve to the same bucket.
  • There's no authentication — anyone with the URL can publish. Fine for personal/hobby use.
