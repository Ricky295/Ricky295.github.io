Why do we only need 2 points? A Log-Normal distribution is fully parameterized by two variables: location ($\mu$) and scale ($\sigma$). Given exact percentiles like P50 and P95, we set up a linear system of equations using the inverse Cumulative Distribution Function (CDF) of the normal distribution to derive $\mu$ and $\sigma$ precisely.
