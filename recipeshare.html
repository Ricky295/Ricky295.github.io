Recipe Share API

Read-only recipe data is available with HTTP GET requests. Responses are JSON by default. Add a callback parameter for JSONP.

Search and filter

Combine these parameters as needed: search, tag, maxPrepTime, maxCookTime, minRating, and maxRating.

Response shape

{ "ok": true, "recipes": [{ "id": "…", "title": "…", "prepTime": 20, "cookTime": 60, "averageRating": 4.5 }] }

Times are integer minutes. Ratings range from 1 to 5; recipes without reviews have an average rating of 0.
