Parameter reference

    
All parameters are optional query-string additions to this same page's URL. Anything unset falls back to its default. Presence of a recognized parameter (like sudoku) is what switches this page from this designer into the live grid.

    

      
ParameterDefaultDescription

      
        
sudoku32Either an 81-character string of givens (digits 0–9, . or 0 for blank) to load a fixed board, or a number. Numbers 17–81 are treated as a target clue count for generation; 1–4 map to named difficulty tiers (easy/medium/hard/expert).

        
size320Total board width in pixels (the widget is always square). Cell size, gridlines, and font scale derive from this.

        
cellsize—Direct per-cell pixel size, if you'd rather size by cell than by total board width. Overrides size if both are set.

        
seedrandomInteger seed for the puzzle generator. Same seed + same clue target reproduces the same puzzle. Ignored when sudoku is a fixed 81-digit string.

        
themelightlight or dark.

        
accent3B5BA9Hex color (no #) used for given digits and highlights.

        
timeronSet to off to hide the timer.

        
timerspace—Reserved layout hint for host pages reserving vertical space for the timer row; accepted but not required.

        
mistakesonSet to off to hide the mistake counter.

        
autocheckonSet to off to stop live-highlighting incorrect entries in red.

        
highlightsonSet to off to disable highlighting of peer rows, columns, and squares.

        
numpadonSet to off to hide the on-screen number pad (keyboard input still works).

        
controlsonSet to off to hide the Notes / Erase / New row.

        
transparentfalseSet to true to drop the widget's own background so it blends with the host page behind the iframe.

      
    

    
The widget posts a window.postMessage event of the form { type: 'sudoku-solved', time, mistakes } to its parent frame when solved, if you want to react to completion from the host page.
